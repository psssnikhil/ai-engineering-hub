# Project 4: Tool-Using Autonomous Research Agent

An autonomous research agent that decomposes goals, executes multi-step web research and mathematical calculations using tools, and synthesizes structured markdown reports.

## Features
- **ReAct Execution Loop**: Reason-and-act cycle with complete step tracing.
- **Tool Suite**: Web search, safe math calculation, and markdown synthesis.
- **Trace History**: Step-by-step audit log of agent thoughts, actions, and observations.

## Quick Start

```bash
cd labs/projects/04-research-agent
python main.py
```
