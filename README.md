## 🚀 Run Locally

```bash
git clone https://github.com/psssnikhil/ai-engineering-hub.git
cd ai-engineering-hub
pip install -r requirements.txt
npm install
mkdocs serve
```
Open **[http://127.0.0.1:8000](http://127.0.0.1:8000)** in your browser.
